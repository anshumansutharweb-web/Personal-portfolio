## ✦ Real Form Delivery & Production Setup

### Current Out-of-the-Box Implementation (Static & Secure)
- **Zero Third-Party Servers:** When the user submits the form, client-side JavaScript validates all fields (Name, Email format, Service Required, Project Description), verifies the honeypot spam protection field, and displays a loading state.
- **Structured Mailto Compilation:** It compiles a structured email draft with subject `[Project Enquiry] {Service} - {Name}` and launches the user's default email client (Gmail, Apple Mail, Outlook).
- **Clipboard Fallback:** The status box displays the compiled text, provides a direct clickable mailto link, and includes a **"Copy Details to Clipboard"** button. If the user's device does not have a default email application configured, they can copy their details with one click and paste them directly into any webmail client to send to `anshumansuthar.web@gmail.com`.
- **Honest Status Messaging:** The interface never falsely claims that an email has been delivered to a backend server unless a real delivery service is configured.

### Connecting a Free-Tier Form Service (Optional for Production)
If you wish to receive form submissions directly into your inbox via an HTTP POST request without opening the visitor's email client, you can connect a standard free-tier form endpoint (such as Formspree, FormSubmit, or Web3Forms):

#### Option A: Using FormSubmit (Zero Account Required, Free)
1. In `index.html`, update the `<form id="contactForm">` tag:
   ```html
   <form id="contactForm" action="https://formsubmit.co/anshumansuthar.web@gmail.com" method="POST">
   ```
2. Add the FormSubmit configuration hidden inputs inside `<form>`:
   ```html
   <input type="hidden" name="_subject" value="New AS Tech Studio Website Enquiry">
   <input type="hidden" name="_captcha" value="false">
   <input type="hidden" name="_template" value="table">
   ```
3. Submit the form once to activate and verify the confirmation email sent to `anshumansuthar.web@gmail.com`.

#### Option B: Using Formspree (Free 50 submissions/month)
1. Create a free account at [formspree.io](https://formspree.io) using `anshumansuthar.web@gmail.com`.
2. Create a new form and copy your endpoint ID (e.g. `https://formspree.io/f/xyzabc123`).
3. In `script.js`, replace the `mailtoUrl` trigger with a `fetch(endpoint, { method: 'POST', body: ... })` call.

*Security Rule:* Never put private API keys or secret credentials in client-side JavaScript.
