# Personal Freelancer Portfolio — Starter

Responsive colorful portfolio starter for an independent web developer in India working with international clients.

## Before publishing
- Your final public name is undecided, so the site currently uses **Your Name** and a temporary **YN** mark. Search `index.html` for `Your Name` and replace each occurrence before publishing.
- The three portfolio items are fictional demo concepts, not paid client projects or claims of commercial results.
- The contact form opens the visitor's email app using `mailto:`. It does not store form submissions or send them to a server.
- This starter is a static HTML/CSS/JavaScript site; React and Node.js are listed as selected skills/services, but this starter itself does not use a React/Node backend. Only accept work you can confidently scope, build, test and maintain.

## Files
- `index.html` — page structure and English copy
- `style.css` — responsive styling
- `script.js` — mobile navigation, year and email form
- `README.md` — setup and deployment notes

## Run locally
1. Extract the ZIP and open the folder in VS Code.
2. Open `index.html` in a browser, or use the free VS Code Live Server extension.

## Free hosting using GitHub Pages
1. Create a free GitHub account and a public repository such as `my-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Once deployed, GitHub will show the live URL in the Pages section.
